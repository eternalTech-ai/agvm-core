# Support

AGVM Core support is community-first until the first public release is tagged.

## Where To Ask

- Use GitHub Issues for reproducible Core bugs, documentation gaps and local MCP
  setup problems.
- Use GitHub Discussions if enabled for general questions and integration notes.
- Use SECURITY.md for vulnerabilities, leaked secrets or private data exposure.

## What To Include

- AGVM Core commit or release version.
- Operating system and Docker version.
- Local API health result from `http://127.0.0.1:8010/health`.
- MCP client name and sanitized configuration.
- Logs with provider keys, local paths and brain contents removed.

## Out Of Scope

Public Core support does not cover Detwin Cloud billing, private module source,
tenant data, customer brains or proprietary deployment infrastructure. Those
flows are handled by the Detwin platform support channel.
