# Code Of Conduct

AGVM Core contributors are expected to keep discussion technical, respectful and
focused on making the public core safe, useful and maintainable.

## Expected Behavior

- Be direct and constructive.
- Assume public issues and pull requests may be read by future operators.
- Keep sensitive data, provider keys, local brains and customer information out
  of public discussions.
- Respect the public/private boundary: do not request, post or review paid
  module source or private platform code in this repository.

## Unacceptable Behavior

- Harassment, threats, personal attacks or sustained disruptive comments.
- Publishing another person's private information.
- Posting secrets, customer data or private AGVM source.
- Using public issues to bypass product, billing or entitlement boundaries.

## Enforcement

Maintainers may edit, hide or delete content; close issues; block accounts; or
remove repository access when conduct or security risk requires it. Security
reports should follow SECURITY.md instead of public issue threads.
