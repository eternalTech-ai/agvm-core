# AGVM Core Runtime Constitution

This public runtime document defines the bounded contracts used by AGVM Core.
It contains no customer data, deployment secrets, private module behavior, or
proprietary implementation material.

## PRODUCT DEFINITION

AGVM Core is a local-first memory and retrieval runtime. Reviewed sources are
compiled into evidence-bearing nodes with coordinates, topology, provenance,
and exact source anchors. Answers must remain grounded in promoted evidence.

## AI-CORE RUNTIME CONTRACT

Semantic planning is AI-authored and fail-closed. When the provider is missing,
rate limited, out of quota, or returns an invalid contract, Core reports that
provider state and does not manufacture an equivalent heuristic result.

## COORDINATE SYSTEM

Retrieval authority comes from normalized semantic coordinates, topology,
source evidence, Metamemory, and per-brain revisions. Display metadata such as
`memory_type`, `guide_area`, labels, and tags is never routing authority.

## AI SPATIAL LANDING CONTRACT

For every admitted answer strand, the planner authors one inverse answer path
with ordered destinations expressed as a region reference, an explicit
coordinate, or a declared novel-region candidate. The backend validates the
plan, snaps bounded coordinates, and executes it. There is no deterministic or
metadata-based landing fallback.

## RETRIEVAL

Execution scans landing spheres and path tubes, walks local links, uses
highways for justified long-range motion, and follows evidence edges as
provenance. Exact source text is hydrated only after evidence promotion.

## CONTEXT

The client receives a cited context package with route and materialization
truth. Missing AI material, missing evidence, stale revisions, and provider
errors remain explicit blockers rather than being hidden by a partial package.

## COGNITIVE GROW

Grow is review-first. A source preview is non-mutating; apply requires an exact
selection, confirmation, idempotency, and a revision guard. Stored claims keep
their source anchors and chronology.

## MCP

MCP tools preserve brain scope, expose stable JSON contracts, and distinguish
terminal, partial, pending, and blocked states. Tool visibility never grants a
paid capability or bypasses local authorization.

## HEURISTIC LEARNING AND MAINTENANCE

Heuristics may assist bounded execution but cannot certify an AI-required
semantic result. Sleep, Evolve, and calibration remain reviewable,
revision-bound, and reversible.
